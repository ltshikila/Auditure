# Episode Snippets Calendar — March 2026

> This is a living document. Books may be swapped based on real-time trends, viral moments, or adaptation announcements. Check Twitter/BookTok pulse before finalizing each day's episode.

## How to Use
1. Generate the episode in Auditure using the listed book + chapters
2. Find the best 30-45s section (use Claude to identify timestamp)
3. Edit in CapCut: bold text hook as first frame (3-5s), then book cover + captions enter, kinetic typography, audiowaves
4. Post at 3-4pm SAST (9-10am EST) using the post template
5. If a book is trending that day, swap it in — ride the wave

### VP Creation Video Ideas (Rotate These)
- Same book, two different podcaster personalities, different output
- Naming a podcaster and showing what it produces
- Debate format vs discussion format on the same chapters
- "My [name] podcaster covered [book] and this is what it said"
- A podcaster with an unexpected style covering a well-known book

### What NOT to Post
- Build in public updates (pre-launch energy, we're past that)
- Direct CTAs ("Download now"). Bio handles the funnel.
- Long threads explaining the product
- Feature announcements without a content hook

## Format Mix Target
- **Debate**: 3-4 per week (drives engagement, polarizing takes)
- **Discussion**: 3-4 per week (accessible, storytelling-focused)
- **Lecture**: Save for deep educational content (1 per week max if needed)

## Audience Lane Rotation
Each day's pick should target at least one of these lanes:
1. **Tech/AI** — indirect (the app itself is the tech angle)
2. **Book Twitter** — fiction picks, BookTok crossovers
3. **Podcast listeners** — "turn any book into a podcast" angle
4. **Self-improvement** — non-fiction picks (Rich Dad, Atomic Habits, etc.)
5. **Entertainment/TV** — adaptation tie-ins
6. **Education** — classics, philosophy, history
